# Uniblox OS 7 (32x Pro)

Uniblox OS 7 32x Pro is a complete desktop-mode ecosystem packaged into a single 1 GB ARM APK. Built using x86 architectural frameworks, it features a native .deb to .uea execution decoder to run advanced software directly on your Android tablet.

## What's New in Version 7 (Upgrading from v6)
* 🚀 **Real Freeform Windows:** No more rigid layouts. Apps can now be resized, dragged, and stacked.
* 🖥️ **Redesigned Desktop Interface:** Dropped the old, boring v6 start menu for a completely modernized desktop layout.
* 📦 **Self-Contained Engine:** All translation layers and system components are safely baked into the 1 GB package.

## 🛠️ Critical Setup: Enabling Freeform Windows
Because Version 7 utilizes advanced system scaling, you MUST enable freeform windows in Android's developer settings for the OS to function correctly:

1. On your tablet, go to **Settings > About Tablet**.
2. Tap **Build Number** 7 times until it says *"You are now a developer"*.
3. Go back to **Settings > System > Developer Options**.
4. Scroll down near the bottom and toggle ON:
   * **Enable freeform windows**
   * **Force activities to be resizable**
5. **Restart your tablet** and launch Uniblox OS 7!
